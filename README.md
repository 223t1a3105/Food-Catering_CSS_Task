# Food Collage Web Design

## Project Overview

A responsive food collage webpage created using **HTML5 and CSS3**, inspired by the provided reference design.

## Technologies Used

* HTML5
* CSS3

## CSS Concepts Used

* CSS Selectors
* `transform`
* `transition`
* `:hover` effects
* Responsive Design
* CSS Positioning
* Pseudo-elements

## Features

* Diamond-shaped food images
* Center highlighted image
* Decorative background elements
* Smooth hover animations
* Responsive layout

## How to Run

1. Download or clone the project.
2. Open the project folder in VS Code.
3. Open `index.html`.
4. Run using **Live Server** or open it in a web browser.
